# zheyangby-notes

Cloud engineer · AWS and CDK

留着备查的示例

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/zheyangby-notes.git
cd zheyangby-notes
pip install -r requirements.txt
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
